# カスタムフィールド

カスタムフィールドを使うと、Redmine のいくつかの種類のデータに情報を追加できます。カスタムフィールドを使えるデータの種類は、「[カスタムフィールドの種類](custom-fields.md#Custom-field-types)」を参照してください。\
カスタムフィールドごとに、[形式](custom-fields.md#Custom-field-supporting-data-types)を設定できます。

## カスタムフィールドの種類

### 形式

カスタムフィールドの形式は、次のいずれかです。

- **真偽値**: チェックボックス
- **日付**: 日付
- **ファイル**: オブジェクトに添付するファイル
- **小数**: 浮動小数点数
- **整数**: 正または負の数
- **キー・バリュー リスト**: 値の名前を変更できるドロップダウンリスト ([リストとキー・バリュー リスト](custom-fields.md#Lists-and-KeyValues-list)を参照)
- **リンク**: URL
- **リスト**: ドロップダウンリスト
- **長いテキスト**: サイズを変更できる複数行のテキスト (バージョン 2.5.0 からリッチテキストの書式に対応)
- **進捗バー**: 0 から 100 までの割合を進捗バーで表示 (6.1.0 から)
- **テキスト**: 1 行のテキスト (バージョン 2.5.0 からリッチテキストの書式に対応)
- **ユーザー**: プロジェクトのメンバーを参照するのに使える形式
- **バージョン**: バージョンを参照するのに使える形式

### 検証

カスタムフィールドごとに、いくつかの検証を設定できます。

- 「最短 - 最大長」: フィールドの最小と最大の長さ (0 は制限なし)
- 「正規表現」: 正規表現でフィールドの内容を検証できます。例:
  1.  *英大文字 4 文字の後に 1 文字以上の数字*

      ```text
      ^\[A-Z]{4}\d+$
      ```

  2.  *数字を含まない文字列*

      ```text
      ^[^0-9]*$
      ```

- 正規表現の一覧は、Ruby Users Guide にあります。

### 値

複数の値やデフォルト値に対応しているフィールドもあります。

- **複数選択可**: 有効にすると、複数の項目を選択できます。
- **選択肢**: 「リスト」のフィールドで選択できる値です。1 行に 1 つの値を書きます。
- **デフォルト値**: 何も選択されていないときに設定する値です。

### テキスト書式

テキストの書式に対応しているフィールドもあります。

- **テキスト書式**: テキストを Wiki の書式で表示するかどうかです。有効にすると、「値に設定するリンクURL」のフィールドは*ロック*されます。

### リストとキー・バリュー リスト

ユーザーが選択する値の一覧を、自分で作成できます。「リスト」の形式の値を後から変更しても、過去に作成した既存のレコードには影響しません。「キー・バリュー リスト」の値を変更すると、過去に作成した既存のレコードにも反映されます。

### 値に設定するリンクURL

「値に設定するリンクURL」は、真偽値、日付、小数、整数、キー・バリュー リスト、リスト、テキストの形式のフィールドで設定できます。

- **値に設定するリンクURL**: 次の変数を使って URL を作ります。
  - `%value%` =\> カスタムフィールドの値
  - `%id%` =\> カスタムフィールドを設定したオブジェクトの ID
  - `%project_id%` =\> カスタムフィールドを設定したオブジェクトのプロジェクトの ID (あるとき)
  - `%project_identifier%` =\> カスタムフィールドを設定したオブジェクトのプロジェクトの識別子 (あるとき)
  - `%m1%, %m2%...` =\> カスタムフィールドの正規表現のキャプチャグループに一致した文字列 (正規表現を設定しているとき)

例:

```text
https://www.redmine.org/issues/%value%
```

### 入力欄の表示

(2.5.2 以降) フィールドによっては、ラジオボタンやチェックボックスで表示できます。動作は、選択した「形式」によって少し異なります。

- **真偽値**: チェックボックス (有効/無効) またはラジオボタン (空/はい/いいえ)
- **リスト**、**ユーザー**、**バージョン**:
  - チェックボックス (「複数選択可」が有効のとき)
  - ラジオボタン (「複数選択可」が無効のとき)

## カスタムフィールドを使えるデータの種類

### チケットのフィールド

チケットのカスタムフィールドのデータは、[チケット](../user/issues.md)、[チケット一覧](../user/issue-list.md)、[カスタムクエリ](../user/issue-list.md#Custom-queries)、[作業時間のレポート](../user/timelog-report.md)で使われたり、表示されたりします。

- **トラッカー**: TODO
- **必須**: チケットを作成または保存するときに必須のフィールドです
- **全プロジェクト向け**: チェックを入れると、すべてのプロジェクトのチケットでこのフィールドを使います。チェックを外すと、プロジェクトごとに、チケットでこのフィールドを使うかどうかを選択できます ([プロジェクト設定](../user/project-settings.md)を参照)。
- **フィルタとして使用**: TODO
- **検索対象**: Redmine の[検索](../user/search.md)で検索できるフィールドです

### 作業時間のフィールド

作業時間のカスタムフィールドのデータは、[作業時間のレポート](../user/timelog-report.md)で使われたり、表示されたりします。

- **必須**: 作業時間を作成または保存するときに必須のフィールドです

### プロジェクトのフィールド

プロジェクトのカスタムフィールドのデータは、プロジェクトの[「概要」](../user/project-overview.md)で使われたり、表示されたりします。

- **必須**: プロジェクトを作成または保存するときに必須のフィールドです
- **検索対象**: Redmine の[検索](../user/search.md)で検索できるフィールドです

### バージョンのフィールド

バージョンのカスタムフィールドのデータは、[ロードマップ](../user/roadmap.md)と[バージョン](../user/version.md)の画面で使われたり、表示されたりします。

- **必須**: バージョンを作成または保存するときに必須のフィールドです

### ユーザーのフィールド

ユーザーのカスタムフィールドのデータは、[ユーザーのプロフィール](https://www.redmine.org/projects/redmine/wiki/RedmineUserProfiles)で使われたり、表示されたりします。

- **必須**: ユーザーを作成または保存するときに必須のフィールドです
- **表示**: [ユーザーのプロフィール](https://www.redmine.org/projects/redmine/wiki/RedmineUserProfiles)に表示するフィールドです
- **編集可能**: そのユーザーアカウントの[Redmine のユーザー](../user/accounts.md)本人が編集できるフィールドです

### グループのフィールド

グループのカスタムフィールドのデータは、グループのフォームで編集でき、グループのページに表示されます。

### 作業分類 (時間管理) のフィールド

作業分類のカスタムフィールドのデータは、[作業時間のレポート](../user/timelog-report.md)と[プロジェクト設定](../user/project-settings.md#Activities-time-tracking)で使われたり、表示されたりします<sup>1</sup>。この便利な機能について詳しくは、[#4077](https://www.redmine.org/issues/4077) も参照してください。

- **必須**: 作業分類を作成または保存するときに必須のフィールドです

### チケットの優先度のフィールド

**注記**: チケットの優先度のカスタムフィールドは、Redmine 本体では (まだ) 使われていません。ただし、ほかのプラグインやテーマが使うことは*あります*。今のところ、ここの設定は Redmine のほかの部分には影響しません。

### 文書カテゴリのフィールド

**注記**: 文書カテゴリのカスタムフィールドは、Redmine 本体では (まだ) 使われていません。ただし、ほかのプラグインやテーマが使うことは*あります*。今のところ、ここの設定は Redmine のほかの部分には影響しません。

<sup>1</sup> 例外があります。[#19121](https://www.redmine.org/issues/19121)#note-1 を参照してください。
