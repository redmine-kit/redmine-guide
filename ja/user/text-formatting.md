# テキスト書式

Redmine は、設定 (「管理」→「設定」→「全般」→「テキスト書式」) に応じて、2 種類の書式の構文に対応しています。

- [Textile](text-formatting-textile.md)
- [Markdown](text-formatting-markdown.md) (CommonMark Markdown (GitHub Flavored)、デフォルト)
- [コードハイライトの対応言語](code-highlighting-languages.md)
