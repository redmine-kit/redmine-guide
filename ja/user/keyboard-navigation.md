# キーボード操作

Redmine のキーボードショートカットには 2 種類あります。ブラウザーが提供するアクセスキーと、Redmine 自身が処理するため、どのブラウザーでも同じように動作するショートカットです。

## アクセスキー

Redmine の一部の機能は、アクセスキーで使えます。\
アクセスキーを使うための修飾キーは、ブラウザーとオペレーティングシステムによって異なります。

| ブラウザー | Windows | macOS | Linux | 備考 |
|----|----|----|----|----|
| **Chrome** | Alt | Ctrl + Option | Alt + Shift | Windows と Linux では、アクセスキー **7** と **4** を使えません。Windows では、アクセスキー **e** と **f** には、代わりに Alt + Shift を使います。 |
| **Firefox** | Alt + Shift | Ctrl + Option | Alt + Shift |  |
| **Safari** | 該当なし | Ctrl + Option | 該当なし | Safari は macOS でのみ使用できます。 |
| **Edge** | Alt | Ctrl + Option | Alt + Shift | Chrome と同じです。 |

## アクセスキーを使わないショートカット

次のショートカットは Redmine 自身が処理するため、どのブラウザーでも同じように動作します。

### ナビゲーションのショートカット

| キーボードショートカット | 説明 | 使用できる場所 |
|----|----|----|
| → | 次のファイルに移動します。 | 添付ファイルのプレビューと、リポジトリブラウザーのファイルのページ。**バージョン 4.0 以降で使用できます。** |
| ← | 前のファイルに移動します。 | 添付ファイルのプレビューと、リポジトリブラウザーのファイルのページ。**バージョン 4.0 以降で使用できます。** |
| ↑ / ↓ | 項目を移動します。 | 「プロジェクトへ移動...」のボックス。 |
| Home / End | 最初 / 最後の項目に移動します。 | 「プロジェクトへ移動...」のボックス。 |

### テキストエディターのショートカット

| キーボードショートカット | 説明 | 使用できる場所 |
|----|----|----|
| ⌘ + b (Mac) / Ctrl + b | 選択したテキストを太字にします。 | Wiki のツールバーのあるテキストフィールド。**バージョン 4.2 以降で使用できます。** |
| ⌘ + i (Mac) / Ctrl + i | 選択したテキストを斜体にします。 | Wiki のツールバーのあるテキストフィールド。**バージョン 4.2 以降で使用できます。** |
| ⌘ + u (Mac) / Ctrl + u | 選択したテキストに下線を引きます。 | Wiki のツールバーのあるテキストフィールド。**バージョン 4.2 以降で使用できます。** |
| ⌘ + Shift + p (Mac) / Ctrl + Shift + p | 「編集」と「プレビュー」のタブを切り替えます。 | Wiki のツールバーとプレビューのタブのあるテキストフィールド。**バージョン 4.2 以降で使用できます。** |
| ⌘ + Return (Mac) / Ctrl + Enter | フォームを送信します。 | フォームの中のテキストエリアにフォーカスがあるとき。**バージョン 4.2 以降で使用できます。** |
| Tab / Shift + Tab | 選択した行のインデントを、スペース 2 つ分増やすか減らします。 | CommonMark Markdown の書式を使うテキストエリアで、テキストを選択しているとき。**バージョン 7.0 以降で使用できます。** |
