# 翻訳する

言葉遣いには特に気を付けます。翻訳は、説明している画面と並べて読まれます。

<a id="rules"></a>

## 決まり

- **画面の用語は Redmine の表示どおり:** メニュー、タブ、フィールド、ボタン、設定、権限、ステータスは、Redmine 7.0.3 の `config/locales/<言語>.yml` の文字列で書き、画面と同じ言葉で見つけられるようにします。`glossary/<言語>.yml` で調べ、訳し直しません。名前であることが分かるように、日本語では「適用」(または **適用**)のように書きます。
- **定番の用語:** ロケールにない用語は、新しく言葉を作らず、その言語のソフトウェアで定着した用語を使います(日本語は Microsoft の用語集と日本語スタイルガイド)。出典を付けて `glossary/<言語>.extra.yml` に足します。
- **用語をそろえる:** 同じものは、どのページでも同じ名前にします。
- **ページの題名:** ページの H1 は `glossary/<言語>.pages.yml` の題名にします。画面を説明するページは、Redmine がその画面に付けている名前にします。ほかのページから指すときも同じ題名を使います。
- **自然で正確に:** 逐語訳ではなく、その言語の技術文書の書き手が書くように書きます。意味はそのまま保ち、足したり削ったりしません。ページの構成、リンク、画像は保ちます。
- **見出しは一対一:** 英語のページと同じ数と階層の見出しを、同じ順に置きます。Redmine Help は英語のアンカー(`settings.md#Authentication`、`map.yml`)を見出しの位置で翻訳の見出しに対応させます。リンクは英語のアンカーのまま書き、翻訳にアンカーのタグは足しません。
- **画像:** 英語のページの画像の参照を保ちます。`bin/screenshots` が言語ごとのスクリーンショットを撮り、参照をそれに切り替えます。
- **日本語:** 平易で正確な日本語にし、組織の言葉の決まりに従います。「知らせ」ではなく「通知」、「確かめ」ではなく「確認」、「インストール」、「コピー」、「バージョンアップ」、「例外を発生させる」。バージョンの意味で「版」は使いません。
- **確認する:** コミットの前に、翻訳を英語のページと Redmine 7.0.3 の画面と照らし合わせて読みます。

<a id="a-new-translation"></a>

## 新しい翻訳

1. 英語のページと同じパスにします。`en/user/news.md` は `ja/user/news.md` です。
2. 出典のページと、英語のページのバージョンを front matter に書きます。

   ```yaml
   ---
   source: RedmineNews
   translated_from_version: 12
   ---
   ```

3. 画像とリンクを保ったまま、ページを翻訳します(まだ翻訳していないページへのリンクも使えます。Redmine Help はそのページを英語で表示します)。
4. 検査を流します。

   ```sh
   bin/check
   ```

<a id="glossary"></a>

## 用語集

`glossary/<言語>.yml` には、Redmine の画面の文字列(ラベル、フィールド、ボタン、設定、権限、プロジェクトのモジュール、デフォルトデータ)の英語とその言語が並びます。Redmine のロケールのファイルから作ります。

```sh
bin/glossary ja
```

ガイドが Redmine の新しいバージョンに合わせるときに、作り直します(`REDMINE_VERSION`、`REDMINE_SHA256`)。

<a id="checks"></a>

## 検査

`bin/check`(CI でも動く)は、次のものを報告します。

- ページや画像への切れたリンク
- `translated_from_version` のない翻訳、または英語のページの古いバージョンから作った翻訳
- 英語のページが太字(**Apply**)にしていて用語集にある画面の用語で、翻訳がそれを Redmine の文字列で名前として(「適用」)書いていないもの
- `map.yml` や `index.yml` のトピックや見出しのうち、存在しないもの。`index.yml` の言語のどれかでタイトルのないトピック
- H1 が `glossary/<言語>.pages.yml` の題名でない翻訳、見出しの数や階層が英語のページと違う翻訳、アンカーのタグがある翻訳
- 変換が Textile を残したり、読む人に見える部分を壊したりしたページ (英語と翻訳の両方)。マクロ、コードブロックの中の `<code class>`、エスケープされたリストの記号 (`\*`)、二つに分かれたリスト (`<!-- -->`)、`![#124](...)` のような壊れたリンク、Textile の見出し・表・リンク、Redmine のものでない脚注の記号、Markdown が隠してしまう HTML タグ
