# Text formatting

Redmine supports two syntaxes of formatting based on configuration (Administration → Settings → General → Text formatting)

- [Textile](text-formatting-textile.md)
- [Markdown](text-formatting-markdown.md) (CommonMark Markdown (GitHub Flavored), default)
- [Code highlighting supported languages](code-highlighting-languages.md)
